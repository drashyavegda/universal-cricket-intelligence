# frontend/ — Next.js layer map

> **There is no duplicated source here.** The running Next.js application lives at the repository
> root (`app/`, `lib/`, `components/`, `public/`, `middleware.ts`, `next.config.mjs`). This folder is
> the **organising map** for the phase-2/5 split plus the genuinely missing pieces (public asset
> folders, config/constants/utils, feature specs). Copying `app/` here today would create two
> sources of truth — see `../MIGRATION_MAP.md` §3 and §6.

## 1. What is in this folder

| Path | Status | Purpose |
| --- | --- | --- |
| `src/app/README.md` | map | Route inventory: 29 pages, 25 layouts, 44 API handlers |
| `src/components/<area>/README.md` | map | Which real component belongs to each UI area |
| `src/features/<16>/README.md` | map + spec | One folder per product domain: scope, acceptance criteria, implementation pointers, open items |
| `src/lib/README.md` | map | Maps `lib/**` (40 core modules) into this taxonomy |
| `src/config/*.ts` | **new** | Site config + route constants that reference `lib/site.ts` |
| `src/constants/navigation.ts` | **new** | Typed navigation model for the workspace shell |
| `src/utils/format.ts` | **new** | Safe number/percent/date formatting helpers |
| `src/hooks/`, `src/stores/`, `src/services/`, `src/types/` | map | Documented deliberately-empty areas (no global store, hooks live in pages today) |
| `public/{images,icons,logos,fonts,favicon}/` | **new** | Asset homes; `favicon/` and `logos/` ship real SVGs |
| `public/manifest.json` | **new** | Web app manifest (SVG icons, honest about what exists) |
| `tests/README.md` | map | Where the 151 tests live today and how they move |
| `package.json` | **new** | Phase-5 manifest, pinned to the app's current versions |

## 2. What must NOT be added here

| File | Why |
| --- | --- |
| `public/robots.txt` | Generated by `app/robots.ts`. A static copy would conflict and could leak private paths. |
| `public/sitemap.xml` | Generated by `app/sitemap.ts`. A static copy would go stale and could include private URLs. |
| `public/opengraph-image.*` | Generated at runtime by `app/opengraph-image.tsx` (1200×630). |
| `src/app/**` source copies | Duplicate of the live App Router tree. |
| `next.config.mjs`, `tsconfig.json`, `tailwind.config.ts` | Root-level, single source. Duplicating them splits the build. |

## 3. Target tree (phase 5)

```
frontend/
├── public/            images icons logos fonts favicon manifest.json
├── src/
│   ├── app/           → moved from ../../app/
│   ├── components/    → moved from ../../components/ (split by area)
│   ├── features/      → feature specs + (later) feature-local components
│   ├── lib/           → moved from ../../lib/ (core + client + content + site.ts)
│   ├── config/ constants/ utils/ hooks/ stores/ services/ types/
│   └── middleware.ts  → moved from ../../middleware.ts
├── tests/             → moved from ../../tests/
└── package.json
```

## 4. Moving checklist

1. `git tag pre-frontend-move`
2. `git mv app lib components public types middleware.ts frontend/src/` (adjust paths)
3. Update `tsconfig.json` paths (`@/*` → `frontend/src/*`) and move `vitest.config.ts`
4. Fix imports that assumed repository root (`@/lib/...` keeps working after the path update)
5. `npm run typecheck && npm test && npm run build && npm run smoke` — all five gates
6. Update the two `FRONTEND-ROOT` COPY lines in `/Dockerfile` and the `docker-compose.yml` build
   context; commit.

## 5. Design system notes

Tokens live in `app/globals.css` (`card`, `btn`, `badge`, `input`, `table-base`, `kpi`, `muted`,
`link`, `tab`, `disclaimer`) and in `tailwind.config.ts` (ink/turf/gold/ember/danger palettes).
New UI must compose those classes; a bespoke palette or a one-off button is a review block.
Dark, high-contrast, data-dense; responsive from 375 px; no external fonts (system stack), so no
network dependency and no layout shift.
