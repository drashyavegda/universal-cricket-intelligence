# public/ assets

| Folder | Contents | Notes |
| --- | --- | --- |
| `favicon/` | `icon.svg` | The live favicon is `public/favicon.svg` at the repo root (referenced by `app/layout.tsx`). Keep one source of truth: move the file here only when the phase-5 split happens. |
| `logos/` | `mark.svg` | Brand mark used by the manifest; the in-app lockup is drawn with CSS + lucide icons. |
| `icons/` | README only | Interface icons come from `lucide-react`; this folder is for product/social icons that must be files. |
| `images/` | README only | Photography/illustration. **Nothing is shipped** — the UI is CSS/SVG only, so there are no licensing questions. |
| `fonts/` | README only | The app uses the system font stack (no external fonts, no layout shift, no cookie/consent implications). |
| `manifest.json` | Web app manifest | SVG icons only; PNG 192/512 still needed for full install support. |

## Do not add these files

* `robots.txt` — generated by `app/robots.ts`. A static file would conflict and could accidentally
  allow private routes.
* `sitemap.xml` — generated by `app/sitemap.ts` from the metadata registry; a static copy goes stale.
* `opengraph-image.png` — generated at runtime by `app/opengraph-image.tsx` (1200×630) so the brand
  never drifts from the code.

## Adding an image later

1. Prefer SVG; if raster is unavoidable, export at 2× and keep under 200 KB.
2. Reference it as `/images/<name>.webp` from a component (never an absolute external URL — the
   in-app preview has no network access).
3. Add `width`/`height` to avoid layout shift, and `alt=""` for decorative images.
4. Confirm no licence conflict; record the source in this file.
