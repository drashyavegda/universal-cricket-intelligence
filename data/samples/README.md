# data/samples/

**Every file here is synthetic.** Nothing in this folder is real player data, and none of it is loaded
automatically — the demo workspace is generated by `lib/core/db/seed.ts`.

`sample-players.csv` exists for one purpose: to show an uploader the expected column shape and the
synonym-friendly headers. Two rows, deliberately including one row that produces a validation warning
(`balls_faced = 0` with a strike rate present) so the quality panel can be demonstrated in a demo
without any real data.

The richer demo dataset lives at the repository root in `sample-data/` (6 files, also synthetic).
Anything presented in the UI derived from these rows is labelled `DEMO`.
